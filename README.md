README.md
===
Проект посвящен разработке модели мониторинга теплопотребления и температуры помещения.

## Структура проекта:
- **docx**: Документы Word с проектной документацией.
- **data**: Экспериментальные данные и результаты измерений.
- **src**: Исходный код программы мониторинга.
- **diagrams**: Диаграммы и схемы системы мониторинга.
